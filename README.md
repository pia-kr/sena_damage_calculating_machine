# Can I Clear It Within 4 Turns?

A 4-turn damage calculator for the Destroyer God encounter in Seven Knights Re:Birth.

## Calculator

[Open the calculator](https://pia-kr.github.io/sena_damage_calculating_machine/)

## Features

- Calculates damage using the fixed skill sequence: Sogyo Skill 2 → Pascal Skill 2.
- Configure a five-character party, speed order, formation positions, stats, equipment, and rings.
- Choose critical-hit and weak-point results manually for every attack.
- Choose whether each character's basic attack is skill-enhanced.

## How to use

1. Set Zeo potential and formation in Common Settings.
2. Enter the stats, equipment, and rings for all five characters.
3. Select critical-hit and weak-point results for each attack.
4. Click **Calculate 4-Turn Damage**.

## Notes

- Passive skills and active skills are calculated as fully skill-enhanced. Only basic-attack enhancement can be changed.
- The Defense stat only matters when Milia is included in the party.
- Select **Other** for rings and crafting rings that are not Hunt, Siege, or Avenger.
- Results may differ if game mechanics or balance values change.
